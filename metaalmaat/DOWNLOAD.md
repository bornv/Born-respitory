# JBT Marel Materiaalprijs Converter voor Windows

De broncode staat in deze map. GitHub Actions bouwt en test de Windows-app na wijzigingen op de branch `claude/gallant-hawking-vo5yws` (en `metaalmaat-windows`).

Na een geslaagde build vind je **Materiaalprijs-Converter-Windows.zip** bij de assets van [Materiaalprijs Converter 2.0.1](https://github.com/bornv/Born-respitory/releases/tag/jbt-marel-converter-v2.0.1).

[Volg de Windows-build](https://github.com/bornv/Born-respitory/actions?query=branch%3Aclaude%2Fgallant-hawking-vo5yws).

Pak de ZIP uit en open de exe. Het Excel-invulformat en de handleiding zitten in dezelfde ZIP. De leverancier vult per artikel ook de dichtheid in kg/m³ in.
