Download **Materiaalprijs-Converter-Windows.zip** hieronder bij Assets. Pak de ZIP uit en start de exe.

De ZIP bevat de Windows-app, een Excel-invulformat voor je leverancier en een handleiding.

- Prijzen uit leveranciers-Excel omrekenen tussen kg, ton, meter, m² en stuk.
- De leverancier vult per artikel de dichtheid in kg/m³ in, passend bij de legering.
- Excel-/CSV-export en native Windows-opslagvenster.
- Valutakoersen via ECB/Frankfurter op verzoek; Excelverwerking blijft lokaal.

De app is niet digitaal ondertekend. Windows kan een melding over een onbekende uitgever tonen.
De automatische tests en Windows-build worden bij deze release uitgevoerd. Interactief starten op een Windows-pc is nog niet gecontroleerd.
